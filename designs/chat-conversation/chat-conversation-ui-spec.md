## 1. 基线继承声明

- 继承 `designs/ui-baseline.md`（r1）全部条款，无 token 级偏离。
- 色彩 token 直接引用基线 §2，不重复抄录。
- **布局范式登记**：本模块管理面挂载于**外壳侧边栏中段**（菜单「聊天」下方分割线后的历史会话区，外壳 `01-应用外壳与导航.md` §1.1/§2），不是独立路由的实体列表页，故不适用基线 §4.1「列表页三段式」的全页范式——但三段式的**语义结构**（主操作 → 列表主体 → 分页）在侧栏历史会话区内等比缩小落地：区顶（外壳中段顶部）「＋新建对话」主操作、区中会话行列表、区底轻量分页。登记于此以备走查对照。

## 2. 状态色彩映射（基线 §3 规则 → 本模块映射表）

依据 `chat-conversation-design.md` §5 状态机与 `chat-conversation-ia.md` §5 状态展示表，按基线 §3 规则落成本模块映射：

| 领域状态 | 组件 | 色彩语义 | 说明 |
|---|---|---|---|
| 会话选中 | 列表项背景 | primary-light 高亮 | 选中项 `--el-color-primary-light-9` 底 + 名称 primary 加粗；非选中 blank 底 |
| 空列表（total=0） | 空态引导 | secondary 文本 | 「还没有会话，点击新建开始」——空态非错误 |
| 重命名校验失败 | 行内提示 | danger | 空白/超 100 字行内红字（Element Plus form rules 前置） |
| 删除确认主按钮 | 对话框按钮 | danger | 基线 §3 规则 4：不可逆操作 danger 固定，确认钮承接 |
| PARAM_ERROR | el-message / toast | danger | 重命名保存失败等随服务端信息呈现 |
| NOT_FOUND（会话不存在） | el-message / toast | danger | 统一文案「会话不存在」——重命名/删除/历史查询归属校验统一口径 |

模块附注：本模块列表项**无持续状态 tag**（会话无启用/停用语义），列表元信息 = name / type / crt_time，最近一条消息摘要 Out of Scope 不展示。

## 3. 布局实例化（基线 §4 → 本模块）

### 3.1 会话列表（外壳侧边栏中段）（ia.md §3.1 → P1）

- 会话列表位于外壳侧边栏中段（展开 250px / 折叠 64px 隐藏），列表区域随中段自适应、内部纵向滚动；「＋新建对话」primary 主按钮在外壳中段顶部（→ ai-chat P1 空态）。
- 会话行：名称（单行截断）+ 时间（secondary）；行操作「重命名 / 删除」悬停浮现（text button）。
- 区底轻量分页（`共 n 条 · x/y 页`）；type 过滤透传接口参数（ALL/AI/SCHEDULED）。

### 3.2 历史回看主区（ia.md §3.4 → P4）

- 气泡范式复用 ai-chat ui-spec §3.2（用户右 primary / 助手左 blank + token 尾注 secondary）。
- 按 `id` 升序渲染，分页**向上**加载更多（size ≤50）；内部列（tools/params/media）不展示。
- 历史尾部 = ai-chat 输入区（续聊入口），SSE 消费全部复用 ai-chat 前端——本模块不做流式交互。

### 3.3 表单/确认对话框（基线 §4.2/§4.3 → P2/P3）

- 重命名（P2）：el-dialog + el-form，会话名称必填 ≤100 字，行内校验 + PARAM_ERROR toast 兜底。
- 删除确认（P3）：语义后果声明两条（「仅从列表移除，历史内容仍保留可追溯」「若该会话正在对话中，不受影响」），确认钮 danger。

### 3.4 反馈（基线 §4.4 → 本模块 toast 文案）

- NOT_FOUND：「会话不存在」（danger）
- 重命名非法：随 PARAM_ERROR 信息呈现（danger）
- 删除/重命名成功：轻量成功 toast，列表行自行刷新（基线 §4.4 异步动作原则同源）

## 4. 组件状态清单（供走查）

| 组件 | 需覆盖状态 |
|---|---|
| 会话行 | 选中（primary-light）/ 未选中 / 悬停（行操作浮现）/ 按钮态（删除 danger text） |
| 会话列表 | 有数据 / 空列表（空态引导）/ 分页多页 |
| 重命名字段 | 空 / 合法 / 越界（空白、>100 字）/ 服务端错误 |
| 删除确认 | 常规 / 目标会话正在对话中（文案第二条） |
| 历史消息流 | 短会话（单页）/ 长会话（向上分页加载） |
