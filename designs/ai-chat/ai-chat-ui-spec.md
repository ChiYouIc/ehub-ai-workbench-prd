## 1. 基线继承声明

- 继承 `designs/ui-baseline.md`（r1）全部条款，无 token 级偏离。
- 色彩 token 直接引用基线 §2，不重复抄录。
- **布局范式登记**：对话页为**单栏消息流 + 吸底输入区**布局，不适用基线 §4.1「列表页三段式」——这不是对基线的偏离，而是该范式的适用范围本就不含对话流页面（三段式适用于实体列表页）；本模块按 ia.md §3 的三态画板实例化，登记于此以备走查对照。

## 2. 状态色彩映射（基线 §3 规则 → 本模块映射表）

依据 `ai-chat-design.md` §5 状态机与 `ai-chat-ia.md` §5 状态展示表，按基线 §3 规则落成本模块映射：

| 领域状态 | 组件 | 色彩语义 | 说明 |
|---|---|---|---|
| streaming（流式进行中） | 用户气泡 / 输入区 | primary / 禁用 | 用户气泡 primary 底白字（右侧）；输入区禁用 + 发送⇄停止切换 |
| done（end 事件） | 助手气泡尾注 | secondary | token 汇总灰色次要文本（`输入 n · 输出 n tokens`） |
| error（error 事件） | 内联错误卡 | danger | danger 边框 + danger 文案，助手位内联呈现，非 toast |
| interrupted（中断） | 气泡尾标注 | secondary | 「已中断」灰色标注，**无错误卡**（与 error 分呈现） |
| empty（空态） | 欢迎区 | primary 文本 | 居中欢迎文案，图标 primary |
| 入参错误（PARAM_ERROR） | el-message / toast | danger | 「请输入内容后再发送」等随服务端信息呈现 |
| NOT_FOUND（会话不存在） | el-message / toast | danger | 续聊深链失效场景，统一文案「会话不存在」 |

模块附注：本模块**无持续状态 tag**（无启用/停用类领域状态），基线 §3 规则 2 的「瞬时进行态 primary」在流式体验中的落位 = 流式期间输入控件禁用态 + 用户气泡 primary 底。

## 3. 布局实例化（基线 §4 → 本模块）

### 3.1 对话页三态（ia.md §3 → P1/P2/P3）

- **P1 空态**：居中欢迎区（图标 + 主文案 + 副文案）+ 吸底输入区（max-width 居中）；发送按钮在 prompt 空白时禁用（守卫前置，基线 §4.2 校验两级原则同源）。
- **P2 进行中**：消息流（纵向滚动、自动滚底、增量渲染 + 流式光标 ▌）+ 吸底输入区（禁用态，「回复生成中…」占位 + 「停止」按钮）。
- **P3 错误/中断**：错误 = 助手位内联错误卡（danger 边框，基线 §3 规则 4/5 的非 toast 例外——错误归属对话流内上下文，非全局操作反馈）；中断 = 内容保留 + secondary「已中断」标注。

### 3.2 气泡范式（模块专属）

- 用户气泡：右侧，primary 底白字，圆角 8，max-width 560；
- 助手气泡：左侧，blank 底 + 轻阴影，同宽约束，流式文字 + 光标；end 后尾部 token 汇总（secondary）。
- 历史回看复用同一气泡范式（chat-conversation P4，见该模块 ui-spec §3.2）。

### 3.3 反馈（基线 §4.4 → 本模块 toast 文案）

- 入参空白：「请输入内容后再发送」（danger）
- 续聊深链失效：「会话不存在」（danger，NOT_FOUND 统一句式）
- 流式错误走内联卡不走 toast（见 §3.1 P3），toast 仅承接请求级/入参级错误

## 4. 组件状态清单（供走查）

| 组件 | 需覆盖状态 |
|---|---|
| 输入框 | 空态（发送禁用）/ 可发送 / 流式中禁用（占位「回复生成中…」） |
| 发送/停止按钮 | 发送可用 / 发送禁用（opacity 0.5）/ 停止（流式中） |
| 助手气泡 | 流式渲染（光标 ▌）/ done（token 汇总）/ error（内联卡）/ interrupted（标注） |
| 消息流 | 空态（欢迎区）/ 有消息 / 续聊深链回填历史 |
| toast | 入参错误 / NOT_FOUND |
