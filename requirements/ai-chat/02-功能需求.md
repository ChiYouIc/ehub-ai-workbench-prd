# 02 功能需求 — AI 对话模块

> 模块：ai-chat ｜ 关联 PRD 母本：`plans/ai-chat-sse-prd.md` (v1.0) ｜ 状态：已定版
>
> 编号规则：`FR-xx`，模块内递增不复用。验收标准描述**外部可观察行为**。

## FR-01 发起对话（流式回复）

**需求**：业务用户提交 `prompt` 发起对话，实时流式收到 Agent 回复。

**验收标准**：
1. 有效请求返回 `200` + `text/event-stream`，回复以 `message` 事件逐片推送（增量分片）
2. 正常结束推送 `end` 事件，data 含最终汇总 `{conversationId, models, inputToken, outputToken}`，随后关流
3. 首个 `message` 分片即携带 `conversationId`，前端可据此建立会话

## FR-02 会话组隐式创建

**需求**：首轮对话不传 `conversationId` 时自动创建会话组。

**验收标准**：
1. 新建会话组 `name` 默认取首条 `prompt`，`type` 默认 CHAT=0
2. 新建会话组在首轮调用百炼前先落库（即使百炼失败也留有会话组记录）
3. v1 不提供显式「创建会话组」接口

## FR-03 会话组续聊与归属校验

**需求**：传入 `conversationId` 在已有会话组中继续对话。

**验收标准**：
1. 会话组存在且 `crt_user` = 当前用户 → 续聊，透传该组的百炼 `sessionId`
2. 不存在**或**不属于当前用户 → 统一 `NOT_FOUND "会话不存在"`（不泄露他人会话存在性）

## FR-04 上下文记忆（依赖百炼 sessionId）

**需求**：多轮上下文由百炼 Agent 侧记忆维持。

**验收标准**：
1. 本服务不组装历史 messages、不调用百炼记忆体接口
2. 首次回复后从 Agent 响应取出 `sessionId` 回写会话组（仅首次，已有则不覆盖）

## FR-05 对话内容落库（正常轮次）

**需求**：每轮正常对话结束后保存完整记录。

**验收标准**：
1. 保存 user + assistant 两条 `ai_conversation_content`
2. assistant 记录 `models`（去重逗号连接）、`inputToken`、`outputToken`
3. token 统计缺失时记 0

## FR-06 中断轮次落库（客户端断连）

**需求**：客户端断连被取消的一轮，已产生数据不丢失。

**验收标准**：
1. user 消息 + 已收到的部分 assistant 文本落库
2. assistant `params` 存 `{"interrupted":true,"reason":"client_disconnected"}`

## FR-07 错误轮次落库（百炼失败/空回复）

**需求**：百炼调用失败或空回复的一轮可追溯。

**验收标准**：
1. user 消息 + assistant 错误占位落库，`params` 存 `{"error":true,"code":"<错误码>"}`
2. 空回复判断：流结束仍无任何文本分片
3. 前端收到 `error` 事件（data 含 `{code, message}`），随后关流

## FR-08 客户端断连回收

**需求**：客户端断开后服务端停止拉取百炼输出。

**验收标准**：
1. 注册 `SseEmitter` 的 `onCompletion/onTimeout/onError` 回调
2. 触发任一回调后取消百炼流订阅，不再有新分片被消费
3. 回收后按 FR-06 落库

## FR-09 入参校验

**需求**：流式开始前校验入参，非法请求快速失败。

**验收标准**：
1. `prompt` 空白或超过 8000 字符 → `PARAM_ERROR`（普通 JSON 错误，非 SSE）
2. `type` 不传默认 CHAT=0；传非 CHAT 值 → `PARAM_ERROR`
3. 校验发生在流式开始前，走统一异常包装
