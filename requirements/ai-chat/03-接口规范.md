# 03 接口规范 — AI 对话模块

> 模块：ai-chat ｜ 关联 PRD 母本：`plans/ai-chat-sse-prd.md` (v1.1) ｜ 状态：v1.1（2026-08-25，新增 GET /chat/models、POST /chat/feedback、GET /chat/members、POST /chat/upload）

## 1. 接口定义

### POST /chat/sse

| 项 | 值 |
|---|---|
| 完整路径 | `/ai-workbench/chat/sse` |
| 认证 | 全工程统一约定（见 [`../auth/01-接口认证.md`](../auth/01-接口认证.md)） |
| 请求 Content-Type | `application/json` |
| 响应 Content-Type | `text/event-stream`（`@SkipWrapper`，不走统一响应包装） |
| 说明 | SSE 流式对话。需求原文 `/sse/chat` 已更正为本路径 |

**请求体（ChatParam）**：

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `prompt` | string | 条件必填 | 用户输入，非空白且 ≤8000 字符（传 `regenerateContentId` 时可不传） |
| `conversationId` | long | 否 | 不传 → 隐式创建会话组；传则校验归属后续聊 |
| `name` | string | 否 | 新建会话组名称，默认取 `prompt` |
| `type` | int | 否 | 默认 CHAT=0；v1 仅接受 0 |
| `modelId` | string | 否 | 模型 ID，不传使用默认模型；传无效值 → `PARAM_ERROR` |
| `regenerateContentId` | long | 否 | 重新生成：指定要替换的 assistant 消息 ID，服务端取其上一条 user 消息作为 prompt |
| `fileIds` | long[] | 否 | 上传文件 ID 数组，服务端读取文件内容拼接到 prompt 前部 |

**错误响应（流式开始前，普通 JSON）**：

| 场景 | 错误 |
|---|---|
| `prompt` 空白/超长、`type` 非 CHAT、`modelId` 无效、`fileIds` 含非文本文件、拼接后超长 | `PARAM_ERROR` |
| `conversationId` 不存在/无归属 | `NOT_FOUND "会话不存在"` |
| 认证失败（无有效 JWT） | 见 [`../auth/01-接口认证.md`](../auth/01-接口认证.md) |

## 2. SSE 事件协议

三类事件，均以标准 SSE 帧下发（`event:` + `data:`）。`data` 均为 JSON 字符串。

### event: message（增量分片）

每个百炼增量分片一条事件，前端按序拼接。

```json
{
  "role": "assistant",
  "conversationId": 123,
  "message": "增量文本片段",
  "models": ["qwen-max"],
  "inputToken": 120,
  "outputToken": 35
}
```

| 字段 | 说明 |
|---|---|
| `conversationId` | 首个分片即携带，前端据此建立会话 |
| `message` | 本次增量文本（非全量） |
| `models` / `inputToken` / `outputToken` | 该分片携带的 usage（有则带；最终以 `end` 汇总为准） |

### event: end（正常结束）

```json
{
  "conversationId": 123,
  "models": ["qwen-max"],
  "inputToken": 120,
  "outputToken": 890
}
```

整轮累计值（修正分片累加误差），随后服务端关流。

### event: error（异常）

```json
{
  "code": "BAILIAN_ERROR",
  "message": "Agent 开小差了，请稍后再试"
}
```

百炼调用失败或空回复时下发，随后服务端关流。`message` 为可配置兜底文案（`WorkbenchProperties`），不再使用硬编码 `:::agent-error`。

## 3. 事件时序

```mermaid
sequenceDiagram
    participant FE as 前端
    participant SRV as ehub-ai-workbench
    participant BL as 百炼 Agent

    FE->>SRV: POST /chat/sse {prompt, conversationId?}
    SRV->>SRV: JWT 校验 + 入参校验（失败→JSON 错误）
    SRV->>SRV: 取/建会话组（含归属校验）
    SRV->>BL: Application.streamCall(prompt, sessionId?)
    loop 每个增量分片
        BL-->>SRV: ApplicationResult(text 增量, usage)
        SRV-->>FE: event: message
    end
    BL-->>SRV: 流结束
    SRV->>SRV: 落库 user + assistant（含 token）
    SRV-->>FE: event: end（累计汇总）
```

客户端断连场景见 [02-功能需求](02-功能需求.md) FR-08。

## 5. POST /chat/feedback

| 项 | 值 |
|---|---|
| 完整路径 | `/ai-workbench/chat/feedback` |
| 认证 | 同上 |
| 请求 Content-Type | `application/json` |
| 说明 | 对单条 assistant 消息评价（赞/踩/取消） |

**请求体**：

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `contentId` | long | 是 | assistant 消息 ID |
| `feedback` | string | 是 | 枚举：`up` / `down` / `none`（取消评价） |

**成功响应**：`200`（无 body 或 `{"success":true}`）

**错误响应**：

| 场景 | 错误 |
|---|---|
| `contentId` 不存在或不属于当前用户 | `NOT_FOUND` |
| `feedback` 非法枚举 | `PARAM_ERROR` |

## 6. GET /chat/members

| 项 | 值 |
|---|---|
| 完整路径 | `/ai-workbench/chat/members` |
| 认证 | 同上 |
| 说明 | 模糊搜索可@提及的成员列表 |

**查询参数**：

| 参数 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `keyword` | string | 否 | 模糊匹配姓名，不传返回全量（分页） |
| `pageSize` | int | 否 | 默认 20，最大 50 |

**响应体**：

```json
[
  { "id": 1001, "name": "张运营", "title": "运营专员" },
  { "id": 1002, "name": "李采购", "title": "采购主管" }
]
```

## 7. POST /chat/upload

| 项 | 值 |
|---|---|
| 完整路径 | `/ai-workbench/chat/upload` |
| 认证 | 同上 |
| 请求 Content-Type | `multipart/form-data` |
| 说明 | 上传文本文件，供对话时引用 |

**请求参数**：

| 参数 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `file` | file | 是 | 文件，≤10MB，后缀限 `.txt`/`.csv`/`.json`/`.md` |

**成功响应**：

```json
{
  "fileId": 2001
}
```

**错误响应**：

| 场景 | 错误 |
|---|---|
| 文件超过 10MB | `PARAM_ERROR "文件大小超过限制（最大 10MB）"` |
| 非文本类文件后缀 | `PARAM_ERROR "不支持的文件类型，仅支持 txt/csv/json/md"` |

**使用方式**：上传获得 `fileId` 后，在 `POST /chat/sse` 请求体 `fileIds` 数组中传入。服务端读取文件内容按 `[文件名]\n文件内容\n\n` 格式拼接到 prompt 前部，整体受 8000 字符上限约束。
