# 04 数据模型 — AI 对话模块

> 模块：ai-chat ｜ 关联 PRD 母本：`plans/ai-chat-sse-prd.md` (v1.0) ｜ 状态：已定版
>
> **硬约束：v1 不允许 DDL 变更**（Q8），两表沿用 ehub 库现有结构，全部基于现状列。

## 1. ai_conversation（会话组）

| 列 | 类型 | 说明 |
|---|---|---|
| `id` | bigint PK | 即 `conversationId` |
| `session_id` | varchar | 百炼会话标识；首轮回复后回写，仅首次（见 FR-04） |
| `name` | varchar | 会话组名；隐式创建时默认取首条 prompt（FR-02） |
| `type` | int | 会话类型；v1 仅 CHAT=0 |
| `is_del` | tinyint | 逻辑删除：0 未删 / 1 已删（`@TableLogic`） |
| `crt_time/crt_user/crt_name/crt_host` | — | 创建审计；`crt_user` 是**数据隔离键**（归属校验依据） |
| `upd_*` | — | 更新审计 |

## 2. ai_conversation_content（对话内容）

| 列 | 类型 | 说明 |
|---|---|---|
| `id` | bigint PK | |
| `conversation_id` | bigint | 所属会话组 |
| `role` | varchar | `user` / `assistant` |
| `content` | text | 消息文本；中断轮次存部分文本（FR-06），错误轮次存占位（FR-07） |
| `media_content` | varchar/JSON | 媒体内容；**v1 留空备用** |
| `models` | varchar | assistant 记录，去重后逗号连接（如 `qwen-max,qwen-plus`） |
| `input_token` / `output_token` | int | assistant 记录；usage 缺失记 0 |
| `tools` | varchar | v1 留空备用 |
| `params` | varchar/JSON | 扩展信息，v1 用于轮次结局标记（见下） |
| `crt_*` | — | 创建审计 |

## 3. `params` 列的 v1 用法（轮次结局标记）

不改 DDL 的前提下，用现有 `params` 列区分三种轮次结局：

| 轮次结局 | params 值 | 触发条件 |
|---|---|---|
| 正常 | 空（NULL） | 流正常结束 |
| 中断 | `{"interrupted":true,"reason":"client_disconnected"}` | 客户端断连，订阅被取消 |
| 错误 | `{"error":true,"code":"<错误码>"}` | 百炼调用失败 / 流结束仍无文本分片 |

## 4. 写入时机

| 时机 | 操作 |
|---|---|
| 新建会话组 | 首轮调用百炼**前** insert `ai_conversation` |
| 每轮流式结束后 | 同一事务 insert user + assistant 两条 `ai_conversation_content` |
| 首次收到 sessionId | update `ai_conversation.session_id`（已有值不覆盖） |
