# 04 数据模型 — 会话组与对话内容管理模块

> 模块：chat-conversation ｜ 关联 PRD 母本：`plans/chat-conversation-management-prd.md` (v1.0) ｜ 状态：已定版
>
> **硬约束：v1 不允许 DDL 变更**（延续 v1 Q8），复用现有 `ai_conversation` / `ai_conversation_content` 两表。

## 1. ai_conversation（会话组）

| 列 | 类型 | 说明 |
|---|---|---|
| `id` | bigint PK | 即 `conversationId` |
| `session_id` | varchar | 百炼会话标识（v1 已回写；本模块只读不写） |
| `name` | varchar | 会话组名；本模块「重命名」更新此列 |
| `type` | int | 会话类型；列表过滤依据 |
| `is_del` | tinyint | **逻辑删除键**：0 未删 / 1 已删（`@TableLogic`）；删除操作置 1 |
| `crt_time/crt_user/crt_name/crt_host` | — | 创建审计；`crt_user` 是**数据隔离键**（归属校验依据） |
| `upd_*` | — | 更新审计 |

**本模块操作**：
- 列表：`crt_user = 当前用户` 且 `is_del = 0`，按 `crt_time` 降序分页
- 重命名：update `name`
- 删除：update `is_del = 1`（`@TableLogic` 删除语义）

## 2. ai_conversation_content（对话内容）

| 列 | 类型 | 说明 |
|---|---|---|
| `id` | bigint PK | 历史消息 `id`，查询按此升序 |
| `conversation_id` | bigint | 所属会话组 |
| `role` | varchar | `user` / `assistant` |
| `content` | text | 消息文本 |
| `models` | varchar | assistant 记录模型 |
| `input_token` / `output_token` | int | assistant 记录 token 用量 |
| `media_content` / `tools` / `params` | — | 内部列，**本模块不返回** |
| `crt_*` | — | 创建审计 |

**本模块操作**：
- 查询：`conversation_id = X` 且所属会话组归属校验通过，按 `id` 升序分页
- **不做任何写操作**（无物理删除、无修改）

## 3. 删除语义

| 对象 | 操作 | 说明 |
|---|---|---|
| `ai_conversation` | 逻辑删除（`is_del=1`） | 从列表消失；重命名/查询归属校验失败 → `NOT_FOUND` |
| `ai_conversation_content` | **保留不物理删除** | 保留审计与成本核算数据；随会话组删除对外不可见 |

## 4. 数据隔离与一致性

- 所有查询以 `ai_conversation.crt_user` 为隔离键，先校验归属（存在 + 本人 + 未删），再操作/查询
- 已删会话组的内容行仍在库，但任何对外接口（列表/重命名/历史查询）均不可见
- 本模块不改 `session_id`、不改内容行、不做物理删除，与 v1 主流程无写冲突
