# 03 接口规范 — 模型配置管理

> 模块：model-config（admin 子模块）｜ 关联 PRD 母本：`plans/model-config-prd.md` (v1.0) ｜ 状态：已定版

## 1. 接口总览

所有接口路径前缀：`/ai-workbench/admin`

| 接口 | 方法 | 路径 | 说明 |
|---|---|---|---|
| Provider 列表 | GET | `/model-provider` | 全量查询 |
| Provider 详情 | GET | `/model-provider/{id}` | 按 ID 查询 |
| 新增 Provider | POST | `/model-provider` | |
| 编辑 Provider | PUT | `/model-provider/{id}` | code 不可改 |
| 启用/禁用 Provider | PUT | `/model-provider/{id}/toggle` | 有启用 Model 时阻断 |
| 删除 Provider | DELETE | `/model-provider/{id}` | 软删除 + 级联 |
| Model 列表 | GET | `/model?providerId=` | 按 providerId 过滤 |
| Model 详情 | GET | `/model/{id}` | 按 ID 查询 |
| 新增 Model | POST | `/model` | |
| 编辑 Model | PUT | `/model/{id}` | providerId 不可改 |
| 启用/禁用 Model | PUT | `/model/{id}/toggle` | |
| 删除 Model | DELETE | `/model/{id}` | 软删除 |

所有接口遵循全工程统一认证约定（见 [`../auth/01-接口认证.md`](../auth/01-接口认证.md)），需要管理员权限。

统一响应包装遵循 [`../web/01-响应包装.md`](../web/01-响应包装.md)。

## 2. Provider 接口

### GET /admin/model-provider

全量查询所有未软删除的 Provider，按 `crt_time` 降序。

**成功响应 data**：

```json
[
  {
    "id": 1,
    "name": "OpenAI",
    "code": "OPENAI",
    "baseUrl": "https://api.openai.com/v1",
    "apiKey": "sk-****abcd",
    "authType": "BEARER",
    "extraHeaders": null,
    "enabled": 1,
    "modelCount": 3,
    "crtTime": "2026-08-25 10:00:00",
    "updTime": "2026-08-25 10:00:00"
  }
]
```

| 字段说明 | |
|---|---|
| `apiKey` | 脱敏展示（保留前 3 后 4 字符，中间以 `****` 代替；过短则全 `****`） |
| `modelCount` | 该 Provider 下未软删除的 Model 数量 |

### GET /admin/model-provider/{id}

按 ID 查询详情，响应结构同列表单条。

| 场景 | 错误 |
|---|---|
| ID 不存在或已软删除 | `NOT_FOUND` |

### POST /admin/model-provider

**请求体**：

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `name` | string | 是 | Provider 名称，非空白且 ≤50 字符 |
| `code` | string | 是 | 枚举：`OPENAI` / `DEEPSEEK` / `CLAUDE` / `CUSTOM` |
| `baseUrl` | string | 是 | 合法 HTTP/HTTPS URL，≤500 字符 |
| `apiKey` | string | 是 | API Key 原文（入库前 AES 加密） |
| `authType` | string | 是 | 枚举：`API_KEY` / `BEARER` / `NONE` |
| `extraHeaders` | string | 否 | 自定义请求头，合法 JSON 对象或 null，≤2000 字符 |

**成功响应 data**：新增后的 Provider 完整信息（apiKey 脱敏）。

**错误响应**：

| 场景 | 错误 |
|---|---|
| 任一必填字段缺失/空白/超长 | `PARAM_ERROR` |
| `code` 非法枚举值 | `PARAM_ERROR` |
| `baseUrl` 非法 URL | `PARAM_ERROR` |
| `authType` 非法枚举值 | `PARAM_ERROR` |
| `extraHeaders` 非 null 且非合法 JSON | `PARAM_ERROR` |
| 同 `code` 的未软删除 Provider 已存在 | `PARAM_ERROR "相同类型的 Provider 已存在"` |

### PUT /admin/model-provider/{id}

编辑 Provider。`code` 不可修改（请求体含 `code` 时忽略，不报错）。

**请求体**（字段均可选，仅更新传入项）：

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `name` | string | 否 | 校验规则同新增 |
| `baseUrl` | string | 否 | 校验规则同新增 |
| `apiKey` | string | 否 | null/不传 → 不修改；传新值 → 重新加密存储 |
| `authType` | string | 否 | 枚举同新增 |
| `extraHeaders` | string | 否 | 合法 JSON 或 null |

**成功响应 data**：更新后的 Provider 完整信息（apiKey 脱敏）。

**错误响应**：

| 场景 | 错误 |
|---|---|
| ID 不存在或已软删除 | `NOT_FOUND` |
| 字段校验失败 | `PARAM_ERROR` |

### PUT /admin/model-provider/{id}/toggle

切换启用状态（`enabled` 0↔1）。无请求体。

**成功响应 data**：更新后的 Provider 完整信息。

**错误响应**：

| 场景 | 错误 |
|---|---|
| ID 不存在或已软删除 | `NOT_FOUND` |
| 禁用时该 Provider 下存在 `enabled=1` 的 Model | `PARAM_ERROR "该 Provider 下存在启用中的模型，请先禁用相关模型"` |

### DELETE /admin/model-provider/{id}

软删除 Provider，**级联软删除**其下所有 Model（无论启用/禁用）。删除前校验：存在启用中的 Model 时阻断（同 toggle 规则）。

**成功响应**：`200`，data 为 null。

**错误响应**：

| 场景 | 错误 |
|---|---|
| ID 不存在或已软删除 | `NOT_FOUND` |
| 存在启用中的 Model | `PARAM_ERROR "该 Provider 下存在启用中的模型，请先禁用相关模型"` |

## 3. Model 接口

### GET /admin/model?providerId={id}

按 Provider 过滤，返回其下所有未软删除的 Model，按 `sort_weight` 升序（同权重按 `crt_time` 升序）。

**查询参数**：

| 参数 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `providerId` | long | 是 | Provider ID |

**成功响应 data**：

```json
[
  {
    "id": 101,
    "providerId": 1,
    "providerName": "OpenAI",
    "name": "GPT-4o",
    "description": "旗舰多模态模型",
    "providerModelId": "gpt-4o",
    "sortWeight": 0,
    "enabled": 1,
    "crtTime": "2026-08-25 10:05:00",
    "updTime": "2026-08-25 10:05:00"
  }
]
```

`providerId` 不存在或已软删除时返回空数组 `[]`。

### GET /admin/model/{id}

按 ID 查询详情，响应结构同列表单条（含 `providerName`）。

| 场景 | 错误 |
|---|---|
| ID 不存在或已软删除 | `NOT_FOUND` |

### POST /admin/model

**请求体**：

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `providerId` | long | 是 | 所属 Provider（须存在且未软删除） |
| `name` | string | 是 | 模型名称，非空白且 ≤100 字符 |
| `description` | string | 否 | 模型描述，≤500 字符 |
| `providerModelId` | string | 是 | Provider 侧模型标识符（如 `gpt-4o`），≤200 字符 |
| `sortWeight` | int | 否 | 排序权重，越小越靠前，默认 0 |

**成功响应 data**：新增后的 Model 完整信息。

**错误响应**：

| 场景 | 错误 |
|---|---|
| `providerId` 不存在或已软删除 | `NOT_FOUND` |
| 必填字段缺失/空白/超长 | `PARAM_ERROR` |
| 同 Provider 下 `providerModelId` 已存在 | `PARAM_ERROR "该 Provider 下已存在相同标识的模型"` |

### PUT /admin/model/{id}

编辑 Model。`providerId` 不可修改（请求体含 `providerId` 时忽略，不报错）。

**请求体**（字段均可选，仅更新传入项）：

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `name` | string | 否 | 校验规则同新增 |
| `description` | string | 否 | ≤500 字符 |
| `providerModelId` | string | 否 | 修改时校验同 Provider 下唯一性 |
| `sortWeight` | int | 否 | |

**成功响应 data**：更新后的 Model 完整信息。

**错误响应**：

| 场景 | 错误 |
|---|---|
| ID 不存在或已软删除 | `NOT_FOUND` |
| 字段校验失败 | `PARAM_ERROR` |
| `providerModelId` 唯一性冲突 | `PARAM_ERROR "该 Provider 下已存在相同标识的模型"` |

### PUT /admin/model/{id}/toggle

切换启用状态（`enabled` 0↔1）。无请求体。

**成功响应 data**：更新后的 Model 完整信息。

| 场景 | 错误 |
|---|---|
| ID 不存在或已软删除 | `NOT_FOUND` |

### DELETE /admin/model/{id}

软删除 Model。

**成功响应**：`200`，data 为 null。

| 场景 | 错误 |
|---|---|
| ID 不存在或已软删除 | `NOT_FOUND` |

## 4. 通用约定

### 4.1 apiKey 脱敏规则

响应中的 `apiKey` 一律脱敏：保留前 3 后 4 字符，中间 `****`；长度 ≤7 时全 `****`。明文仅在入库前出现，任何接口不回显明文。

### 4.2 操作日志

所有写操作（POST/PUT/DELETE）打印 info 级日志，格式：

```
[MODEL_CONFIG] action={CREATE_PROVIDER|UPDATE_PROVIDER|TOGGLE_PROVIDER|DELETE_PROVIDER|CREATE_MODEL|UPDATE_MODEL|TOGGLE_MODEL|DELETE_MODEL}, operator={userId}, targetId={id}, detail={变更摘要}
```

`detail` 不含 apiKey 明文（仅记录「已更新」或「未变更」）。
