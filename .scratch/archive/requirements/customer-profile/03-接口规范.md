# 03 接口规范 — 用户画像模块（新用户转化）

> 模块：customer-profile ｜ 关联 PRD 母本：[`plans/customer-profile/customer-profile-prd.md`](../../plans/customer-profile/customer-profile-prd.md)（v1.3 草案待审） ｜ 状态：**前置拆解稿**（PRD 终审定稿时复核）
>
> 全部接口走统一响应包装（`ResponseType` 免二次包装，见 [`../web/01-响应包装.md`](../web/01-响应包装.md)）；认证遵循全工程统一约定（[`../auth/01-接口认证.md`](../auth/01-接口认证.md)）；错误码复用 `PARAM_ERROR / NOT_FOUND`。
>
> **PII 边界**：本服务链路仅流转 `customerId`（平台 ID，非 PII）；`username`/`nickname` 等 PII 由宿主老系统按 `customerId` 映射渲染，本服务接口不返回也不接收 PII（决策 7/22）。

## 1. 前缀

`/profile/customer`（资源域 = 客户画像；模块 `customer-profile`）。

## 2. 接口定义

### POST /profile/customer/generate

| 项 | 值 |
|---|---|
| 完整路径 | `/ai-workbench/profile/customer/generate` |
| 说明 | 触发生成画像（宿主检索列表行内「生成画像」/ 详情页「重新生成」共用；**异步受理**，抢占成功即返回） |

**请求体**：

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `customerId` | string | 是 | 平台客户 ID（非空白） |

**请求示例**：

```json
{ "customerId": "C10086" }
```

**响应**：成功 → 统一成功响应（异步受理，不代表分析完成）。失败：
- `customerId` 非法 → `PARAM_ERROR`
- 已出池（是否有已支付订单=是）→ `PARAM_ERROR "客户已转化，不在画像范围"`
- 分析进行中（`run_state=RUNNING`）→ `PARAM_ERROR "分析进行中"`

**语义**：
- 触发时实时校验池资格（消费状态）+ 并发占用（行级抢占）
- 分析进度经 `GET /profile/customer/{customerId}` 的 `runState` 观察
- 重新生成与首次生成**同一接口**，由服务端幂等/覆盖语义统一处理

### GET /profile/customer/{customerId}

| 项 | 值 |
|---|---|
| 完整路径 | `/ai-workbench/profile/customer/{customerId}` |
| 说明 | 画像详情（画像卡片渲染数据） |

**响应**：`CustomerProfileDetailVO`

```json
{
  "code": 0,
  "data": {
    "customerId": "C10086",
    "profileJson": { "…画像整包，AI 输出原文…" },
    "leadQuality": "HIGH",
    "intentHeat": "WARM",
    "followPriority": "P1",
    "infoCompleteness": 72,
    "stage": "NOT_BOUND",
    "runState": "IDLE",
    "outOfPool": false,
    "model": "qwen-max",
    "inputToken": 1843,
    "outputToken": 512,
    "updTime": "2026-08-27T15:30:00",
    "runFailed": false,
    "runError": null
  }
}
```

**语义**：
- **无画像** → `data.profileJson=null`（空态非错误；`runState` 返回当前是否分析中），前端展示"暂无 AI 分析"+ 生成入口（Q25）
- 有旧画像 → 返回旧画像 + `updTime`（画像最近时间由通用审计 `upd_time` 承载，Q25）
- 已出池 → 仍可回看（不拒绝）；详情路径发现出池惰性回写 `outOfPool=true`
- 枚举/投影列以英文码出参（HIGH/HOT/P0/NOT_BOUND…，※D-5），中文枚举仅存在于 `profileJson` 整包内

### GET /profile/customer/list

| 项 | 值 |
|---|---|
| 完整路径 | `/ai-workbench/profile/customer/list` |
| 说明 | 画像列表（服务端五筛选 + 默认排序；仅已生成画像客户） |

**Query 参数**：

| 参数 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `page` | int | 否 | 默认 1；`<1` 取 1 |
| `size` | int | 否 | 上限 50，超出截断；非法 → `PARAM_ERROR` |
| `leadQuality` | string | 否 | `HIGH` / `MEDIUM` / `LOW` |
| `intentHeat` | string | 否 | `HOT` / `WARM` / `COLD` |
| `followPriority` | string | 否 | `P0` / `P1` / `P2` / `P3` |
| `infoCompletenessMin` | int | 否 | 0–100 |
| `infoCompletenessMax` | int | 否 | 0–100；`Min > Max` → `PARAM_ERROR` |
| `stage` | string | 否 | `NOT_BOUND` / `BOUND_NO_ORDER` |

**响应**：`TablePageResponse<CustomerProfileListItemVO>`（`{code,total,data}`）

```json
{
  "code": 0,
  "total": 1,
  "data": [
    {
      "customerId": "C10086",
      "leadQuality": "HIGH",
      "intentHeat": "WARM",
      "followPriority": "P1",
      "infoCompleteness": 72,
      "stage": "NOT_BOUND",
      "runState": "IDLE",
      "updTime": "2026-08-27T15:30:00"
    }
  ]
}
```

**语义**：
- 默认排序：`followPriority` 升序（P0 在前）+ `updTime` 降序（最近画像写入在前）
- 默认只返回池内客户（`out_of_pool=0`）；已出池客户回看走详情
- 列表项不含 PII——`customerId` 为平台 ID，宿主前端凭其调老系统检索接口取展示信息
- 筛选枚举非法值 → `PARAM_ERROR`

## 3. 下游数据契约（`customer detail` 出参，文案形态）

> 与 MCP 团队契约对齐（PRD 决策 6/7，随本文件定稿）；本服务侧**只消费下列字段**，解析口径见 FR-05 / 04 列语义。

### 3.1 PII 脱敏清单（原值不出参）

`username` / `nickname` / `first_name` / `chat_account` / `chat_account_type` / `reply_to_email` 等 PII 原值**不出参**；客户标识仅 `customerId`。完整度所需信号以**布尔形态**由下游计算回传（`hasContactWay` / `hasFirstName`）。

### 3.2 字段表

| 信号 | 出参形态 | 空值约定 | 本服务用途 |
|---|---|---|---|
| 是否有已支付订单 | 布尔文案「是/否」 | — | 池资格校验 / 出池判定（口径归数据属主） |
| 绑定店铺 `stores` | 文案「N 家店铺」 | `-` 未绑店 | 转化阶段判定 + 完整度绑店层 + AI 特征 |
| 是否有联系方式 `hasContactWay` | 布尔「是/否」 | — | 完整度联系方式层（chat_account 或 reply_to_email 非空，下游计算） |
| 是否有姓名 `hasFirstName` | 布尔「是/否」 | — | 完整度基础档案层 |
| 公司 `company` | 原文 | `-` | 完整度基础档案层 + AI 特征（业务属性，保留） |
| 国家 `country` | 英文名码（如 US） | `-` | 完整度基础档案层 + AI 特征（粗粒度区域非住址，保留） |
| 注册区域 | 省级中文描述 | `-` | AI 输入特征（**不入完整度基准**） |
| DS 经验 | 枚举文案 | `-` | AI 特征 + 完整度问卷项 |
| 周广告预算 | 枚举文案 | `-` | AI 特征 + 完整度问卷项 |
| 月订单量预期 | 枚举文案 | `-` | AI 特征 + 完整度问卷项 |
| 细分市场 | 原始数字 | `-` | AI 特征 + 完整度问卷项 |
| 意向服务 | 多选逗号串 | `-` | AI 特征 + 完整度问卷项 |
| 最近登录时间 | 时间戳 | `-` | AI 特征（intentHeat） |
| 客户标签 / 用户等级 | 文案 | `-` | AI 特征（leadQuality 参考基线） |
| 渠道来源 / 二级 / Medium / Campaign / 合作来源代码 / 来源链接 | 文案 | `--` 未归因 | 渠道归因层（渠道来源非 `--` 即记已归因，其余细分字段不作填写要求）+ AI 特征 |

**文案解析口径锁定**：本服务只识别空值标记（普通 `-` / 渠道 `--`）与布尔形态「是/否」，**不解析枚举文案语义**（非空即记已填）——防下游文案调整导致脆弱文本解析（PRD 风险 3）。
