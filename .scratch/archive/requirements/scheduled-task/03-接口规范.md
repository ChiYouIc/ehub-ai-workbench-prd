# 03 接口规范 — 定时任务模块

> 模块：scheduled-task ｜ 关联 PRD 母本：`plans/scheduled-task-prd.md`（v1.0 已定版） ｜ 状态：随定版生效
>
> 全部接口走统一响应包装（`ResponseType` 免二次包装）。**接口认证遵循全工程统一约定**（见 [`../auth/01-接口认证.md`](../auth/01-接口认证.md)）。错误码复用既有 `PARAM_ERROR / NOT_FOUND`，不新增。

## 1. 前缀

`/task`（区别于聊天 `/chat`，两类资源不同域）。

## 2. 接口定义

### POST /task

| 项 | 值 |
|---|---|
| 完整路径 | `/ai-workbench/task` |
| 说明 | 创建定时任务 |

**请求体**：

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `name` | string | 是 | 非空白，≤100 字符 |
| `prompt` | string | 是 | 非空白，≤8000 字符 |
| `cronExpression` | string | 是 | Spring 6 段 cron；相邻触发 ≥5 分钟 |

**请求示例**：

```json
{
  "name": "每日晨报",
  "prompt": "汇总昨日订单异常并给出处理建议",
  "cronExpression": "0 0 9 * * *"
}
```

**响应**：成功 → 统一成功响应（含任务 id）。失败 → `PARAM_ERROR`（字段非法 / cron 间隔不足 / 达到 20 个任务上限）。

### GET /task

| 项 | 值 |
|---|---|
| 完整路径 | `/ai-workbench/task` |
| 说明 | 当前用户任务分页列表（`crt_time` 降序） |

**Query 参数**：`page`（默认 1）/ `size`（上限 50），边界同会话组列表。

**响应**：`TablePageResponse<TaskVO>`（`{code,total,data}`）

```json
{
  "code": 0,
  "total": 1,
  "data": [
    {
      "id": 1,
      "name": "每日晨报",
      "prompt": "汇总昨日订单异常并给出处理建议",
      "cronExpression": "0 0 9 * * *",
      "enabled": true,
      "conversationId": 101,
      "nextFireTime": "2026-08-23T09:00:00",
      "lastRunTime": "2026-08-22T09:00:03",
      "lastRunStatus": "SUCCESS",
      "lastRunError": null,
      "crtTime": "2026-08-20T15:30:00"
    }
  ]
}
```

### GET /task/{taskId}

| 项 | 值 |
|---|---|
| 完整路径 | `/ai-workbench/task/{taskId}` |
| 说明 | 任务详情 |

**响应**：`TaskVO`（字段同列表项）。不存在/无归属/已删 → `NOT_FOUND "任务不存在"`。

### PUT /task/{taskId}

| 项 | 值 |
|---|---|
| 完整路径 | `/ai-workbench/task/{taskId}` |
| 说明 | 更新任务（全量字段） |

**请求体**：

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `name` | string | 是 | 同创建校验 |
| `prompt` | string | 是 | 同创建校验 |
| `cronExpression` | string | 是 | 同创建校验（≥5 分钟间隔） |
| `enabled` | boolean | 是 | `true`=启用，`false`=停用 |

**响应**：成功 → 统一成功响应。字段非法 → `PARAM_ERROR`；不存在/无归属/已删 → `NOT_FOUND "任务不存在"`。

**语义**：
- cron 变更或 `enabled` 置 true → 重算 `next_fire_time`
- `enabled=false` → `next_fire_time` 置 null
- 执行中任务的更新对本轮无效，下一轮生效

### DELETE /task/{taskId}

| 项 | 值 |
|---|---|
| 完整路径 | `/ai-workbench/task/{taskId}` |
| 说明 | 删除任务（逻辑删除，绑定会话组保留） |

**响应**：成功 → 统一成功响应。不存在/无归属/已删 → `NOT_FOUND "任务不存在"`。

### POST /task/{taskId}/run

| 项 | 值 |
|---|---|
| 完整路径 | `/ai-workbench/task/{taskId}/run` |
| 说明 | 立即手动执行一次（调试 prompt 用；异步，不等结果） |

**响应**：成功 → 统一成功响应。`run_state=RUNNING` → `PARAM_ERROR "任务正在执行"`；不存在/无归属/已删 → `NOT_FOUND "任务不存在"`。

**语义**：不推进 `next_fire_time`；停用任务也可执行；产出 `params` 标 `{"trigger":"MANUAL","taskId":id}`。

## 3. 越权测试（实现性要求，非新增鉴权）

实现须通过越权测试：用他人 taskId 调 GET/PUT/DELETE/run，一律 `NOT_FOUND "任务不存在"`，不泄露存在性（延续 v1 数据隔离口径）。
