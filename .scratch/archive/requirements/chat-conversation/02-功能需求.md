# 02 功能需求 — 会话组与对话内容管理模块

> 模块：chat-conversation ｜ 关联 PRD 母本：`plans/chat-conversation-management-prd.md` (v1.0) ｜ 状态：已定版
>
> 编号规则：`FR-xx`，模块内递增不复用。验收标准描述**外部可观察行为**。

## FR-01 会话组列表

**需求**：业务用户分页查看自己名下的会话组。

**验收标准**：
1. 返回当前用户（`crt_user`）名下、未逻辑删除的会话组，按 `crt_time` 降序
2. 列表项仅含元信息 `id/name/type/crt_time`，不含最近一条消息摘要
3. `type` 过滤参数可选：不传返回该用户全部类型；传则仅返回该类型
4. 空列表返回 `total=0, data=[]` 而非错误
5. `page<1` 默认 1；`size>50` 截断为 50；`size` 非法值 → `PARAM_ERROR`

## FR-02 会话组重命名

**需求**：业务用户修改某个会话组的名称。

**验收标准**：
1. `name` 非空白且 ≤100 字符，合法则更新成功，返回成功响应
2. `name` 空白或 >100 字符 → `PARAM_ERROR`
3. 会话组不存在 / 不属于当前用户 / 已逻辑删除 → `NOT_FOUND "会话不存在"`
4. 允许重名（无唯一约束）

## FR-03 会话组删除

**需求**：业务用户删除某个会话组。

**验收标准**：
1. 置 `ai_conversation.is_del=1`（逻辑删除），返回成功响应
2. 其下 `ai_conversation_content` 内容行**保留不物理删除**
3. 会话组不存在 / 不属于当前用户 / 已逻辑删除 → `NOT_FOUND "会话不存在"`
4. 已删会话组不再出现在 FR-01 列表、不可被 FR-02 重命名、不可被 FR-04 查询

## FR-04 历史消息查询

**需求**：业务用户按会话组分页查看历史对话内容。

**验收标准**：
1. 返回该会话组下内容，按 `id` 升序（对话自然顺序）
2. 每条返回 `id/role/content/crt_time/models/inputToken/outputToken`
3. 不返回内部列（`tools/params/media_content`）
4. 会话组不存在 / 不属于当前用户 / 已逻辑删除 → `NOT_FOUND "会话不存在"`
5. 分页参数边界同 FR-01（`page<1` 归 1；`size>50` 截断；`size` 非法 → `PARAM_ERROR`）
